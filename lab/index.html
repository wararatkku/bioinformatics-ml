Scenario: You are a bioinformatics data scientist. Your team asks you to build a model that distinguishes two diagnostic groups from biomedical measurements.

Github workflow

Fork → Open Codespace / Clone → Run Notebook → Modify Experiment → Submit

Open notebooks/bioinformatics_ml.ipynb. The notebook loads the Breast Cancer Wisconsin Diagnostic dataset from the project file dataset/cancer.csv, so no external data download is required.

Challenge 1 — Understand the problem

  1. What is the target?
  2. What are the features?
  3. Is this classification or regression?
  4. Which metric matters most in this context?
  5. What risks could make our evaluation misleading?

Challenge 2 — Explore and prepare

Inspect sample count, feature count, target balance, missing values and descriptive statistics. Split the data with stratification. Fit preprocessing on training data only.

Challenge 3 — Compare models

Challenge 4 — Interpret

Identify the Top-5 Random Forest features. Discuss whether predictive importance implies biological causality.

Model Defense

  • Our recommended model is…
  • The most important evaluation metric is… because…
  • The most informative features are…
  • One important limitation is…

Before leaving, make sure your notebook runs and your README summarizes your evidence-based model choice.

Think like a researcher: prediction performance is only part of the evidence.
