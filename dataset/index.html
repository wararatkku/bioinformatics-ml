Breast Cancer Wisconsin Diagnostic Dataset

A compact biomedical classification dataset for learning the complete machine-learning workflow.

Dataset Overview

Predicting Malignant vs. Benign Tumors

The dataset contains numerical characteristics computed from digitized images of fine needle aspirates of breast masses. The learning task is binary classification.

569samples
30predictor features
2classes
0missing values in the supplied CSV

Dataset Source and Citation

The project file dataset/cancer.csv is a local copy of the Breast Cancer Wisconsin (Diagnostic) dataset from the UCI Machine Learning Repository.

Wolberg, W., Street, N., & Mangasarian, O. (1995). Breast Cancer Wisconsin (Diagnostic) [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5DW2B.

Target Variable

ClassMeaning
MalignantCancerous tumor
BenignNon-cancerous tumor

Feature Groups

Ten underlying cell-nucleus characteristics are summarized using mean, standard error, and worst/largest values, producing 30 predictors.

CharacteristicExample variables
Radiusmean radius, radius error, worst radius
Texturemean texture, texture error, worst texture
Perimeter / Areasize-related measurements
Smoothness / Compactnessshape and boundary characteristics
Concavity / Concave pointscontour characteristics
Symmetry / Fractal dimensionshape-complexity characteristics
