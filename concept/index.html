Machine Learning Concepts

Understand how machine learning can support the analysis and interpretation of biological data.

Concept 1

What is Machine Learning?

Machine learning is a computational approach in which algorithms learn patterns from data and use those patterns to make predictions or decisions about new data. In bioinformatics, understanding how a model learns and how its results should be evaluated helps researchers interpret computational evidence responsibly.

Bioinformatics example: A model can learn patterns from biomedical measurements and predict whether a new sample belongs to a diagnostic class. Researchers then evaluate how reliable that prediction is and what its limitations are.
Concept 2

Supervised vs. Unsupervised Learning

Supervised learning

Learn from labeled data. Classification predicts categories, such as disease vs. non-disease; regression predicts continuous values, such as drug response.

Unsupervised learning

Find structure in data without known labels. Clustering can identify groups or subtypes, while dimensionality reduction can summarize high-dimensional biological data.

Deep learning uses neural networks to learn complex representations, for example from biological sequences, images, or large-scale omics data.

Concept 3

Features and Target

Biological sample
      ↓
Features (X) ─────→ Machine Learning Model ─────→ Target (y)

Examples of X: gene expression, protein levels, clinical measurements
Examples of y: disease class, phenotype, drug response

Question: In your research problem, what are X and y?

Concept 4

Training, Validation and Testing

Dataset
  │
  ├── Training Data ──→ Learn model parameters
  ├── Validation / Cross-validation ──→ Tune and select models
  │
  └── Test Data ──→ Final evaluation on unseen data

Use training data to fit the model, validation data or cross-validation to compare choices, and the test set for a final unbiased evaluation. The test set must not influence training, model selection, or preprocessing decisions; otherwise, reported performance may be overly optimistic.

Concept 5

Overfitting and Generalization

Underfitting

The model is too simple to capture meaningful patterns. Performance is poor even on training data.

Good Generalization

The model learns useful patterns and performs consistently on unseen data.

Overfitting

The model learns training-specific noise and performs much worse on unseen data.

Good generalization means a model performs well on new samples drawn from the population it is intended to serve.

Concept 6

Classification Metrics

MetricMain QuestionInterpretation
AccuracyHow often is the model correct overall?Useful when classes and error costs are reasonably balanced.
PrecisionWhen the model predicts positive, how often is it correct?Important when false positives are costly.
Recall / SensitivityHow many actual positives are detected?Important when missing a positive case is costly.
F1-scoreHow well are precision and recall balanced?Useful when both error types matter.
ROC-AUCHow well can the model rank/separate the two classes?Threshold-independent discrimination measure.

Think: For a biomedical screening problem, which metric would you prioritize and why?

Concept 7

High-Dimensional Biological Data

Example: 20,000 genes × 100 patients → p ≫ n, where p is the number of features and n is the number of samples.

In many omics studies, the number of measured variables greatly exceeds the number of patients. A model can fit noise instead of reproducible biology, making this setting especially prone to:

  • Overfitting: excellent training performance but poor results on new patients.
  • Unstable feature selection: small changes in the patient sample can select a different set of genes.
  • The curse of dimensionality: data become sparse and require more samples to estimate patterns reliably.
  • Poor generalization: findings from a small cohort may not transfer to other populations.

Strategies include feature selection to retain informative variables, dimensionality reduction to represent data with fewer variables, and regularization to penalize overly complex models. Use cross-validation to estimate performance robustly and compare choices. Feature selection and all learned preprocessing must happen inside each training fold; doing them before cross-validation leaks information and gives optimistic results.

Concept 8

Data Leakage

Data leakage occurs when information that should be unavailable during training influences the model. For example, scaling the complete dataset before splitting can transfer information from the test set into training.

Incorrect:
Full Dataset → Scale → Train/Test Split

Better:
Full Dataset → Train/Test Split
                  ↓
            Fit preprocessing
            on training data only
Concept 9

Interpretability ≠ Causality

A feature may be highly useful for prediction without being the biological cause of an outcome. Machine-learning feature importance describes predictive contribution within a model—not causal evidence.
