Pre-Class Learning

Arrive ready to experiment. Focus on concepts rather than memorizing algorithms.

1. Data Mining

Data mining is the process of discovering useful patterns and relationships in data. In bioinformatics, it can reveal groups of genes, potential biomarkers, or patient subtypes. Machine-learning methods are often used to help discover these patterns.

2. Machine Learning

Machine learning is a set of methods used in data mining. It learns patterns from examples—such as patient measurements and known diagnoses—and applies what it has learned to predict outcomes for unseen data.

3. Supervised Learning

Features (X) describe each sample; the target (y) is the outcome to predict. Classification predicts categories; regression predicts continuous values.

4. Evaluation

Accuracy alone may be misleading. Consider precision, recall, F1-score and ROC-AUC, especially when errors have unequal consequences.

Concepts to know before class

  • Training set vs. test set
  • Classification vs. regression
  • Overfitting
  • Data leakage
  • Class imbalance
  • Accuracy, precision, recall, F1-score and ROC-AUC
  • Feature importance vs. causality

Pre-Class Questions

  1. A disease classifier achieves 98% accuracy. Is that enough evidence that it is useful? Explain.
  2. Why must the test set remain unseen during model training?
  3. When might recall be more important than precision?
  4. What problem may occur with 20,000 gene features but only 100 patients?
  5. Does a highly important feature prove biological causality? Why or why not?

Bring your answers to class. They will be discussed rather than graded for memorization.
